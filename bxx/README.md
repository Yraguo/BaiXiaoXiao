# 百小鸮 · 微信小程序

百小鸮的独立原生微信小程序实现。使用微信小程序页面、存储和交互能力实现校园学习生活的核心流程。

## 当前功能

- 按周查看课表，左右滑动或点击箭头切换周次
- 自动定位本周，高亮今天和当前节次
- 显示下一节课及倒计时
- 查看课程时间、周次、教室、教师和备注
- 新增、编辑和删除课程，自定义上课周次与颜色
- 设置学期第一周周一、总周数、是否显示周末和每节课时间
- 首次打开自动载入脱敏示例课表
- **日历视图记事**：按月查看，按日期归档，有记事的日期显示圆点，点选某天查看当天待办
- 小鸮本机 Agent：读真实课表回答「本周几节课 / 今天有什么课 / 周三下午有什么课 / 这周哪天没课 / 今天还剩几节 / 下节课在哪上 / 某门课第几周」，支持简称（高数）与错别字、时段筛选（上午/下午/第几节）、多轮追问（那周三呢、它呢）、「记一下 周五交报告」直接建记事、BM25 检索 FAQ 兜底；全程不联网、不调模型。附快捷问题、最近 100 条历史与系统键盘语音入口
- 北京化工大学校园服务九宫格（线性图标）与平台能力提示
- “我的”页数据统计、头像昵称修改（微信头像昵称填写能力）、课表设置和二次确认清理
- **课表导入**：① 选择课表 PDF 本机解析（默认、推荐）；② 教务系统登录直连（部分真机暂无法登录）。导入前可预览、可替换或追加；也可手动新增单门课程
- 全部数据保存到微信本地缓存，PDF 导入不需要任何服务器或网络请求

## 课表导入

课表页课表网格下方的「导入课表」**默认进入 PDF 导入**（教务直连在部分真机过不了，PDF 是本机解析的稳定路径）。页面顶部有**两个并列标签**，可随时切换：

| 方式 | 页面 | 说明 |
|---|---|---|
| PDF 导入 | `pages/pdfimport` | 选择学校课表页导出的 PDF，本机解析后导入；不需要登录、不需要网络请求，默认入口 |
| 教务系统导入 | `pages/import` | 输入学号密码登录正方 jwglxt 自动抓取，可选学年与学期；受微信网络层与学校多节点会话影响，部分真机登录失败 |

两种方式最后都走同一套预览、替换/追加与本地存储流程，导入结果完全兼容。

### ① PDF 导入（默认）

课表页「导入课表」→「选择 PDF 并导入」→ 确认预览 → 选替换或追加。

导出方法：浏览器进入「信息查询 → 学生课表查询」，选好学年学期点「输出 PDF」，把文件发到微信（发给「文件传输助手」即可），再回到小程序里选择。

**不需要登录、不需要学号密码、不需要服务器，也不产生任何网络请求。** 文件只在本机内存中解析，不联网、不上传、不保存。

解析链路全部在小程序内、无第三方依赖：

1. `utils/pdf/inflate.js` 自研 DEFLATE 解压 `FlateDecode` 内容流（与 Node zlib 逐字节一致）
2. `utils/pdf/extract.js` 从 `Tm` / `Td` 取坐标、`Tj` 取文字，按双字节 UCS-2 还原中文
3. `utils/pdf/parser.js` 用「星期一 ~ 星期日」表头锚定七列，按坐标归星期、按行拼接课程块
4. `utils/pdf/courses.js` 映射成课表页使用的课程对象，复用 `parseWeeks` 与 `courseColorIndex`

只支持学校课表页导出的**表格格式** PDF（带文字层、`UniGB-UCS2-H` 编码、`FlateDecode` 内容流）。选错格式、加密 PDF、截图扫描件、模板变化或课程字段不完整都会给出具体原因和处理建议，不会写入半成品。`tests/fixtures/timetable.pdf` 是真实样本，实测还原 21 个课程块、六个字段零缺失。

页面底部会显示「PDF 解析组件：就绪 / 加载失败」。解析模块是按需加载并带异常捕获的：即使模块没打包好，页面也能正常显示和操作，只是选文件时会给出明确提示，不会白屏。

### ② 教务系统直连（目前部分真机无法登录）

课表页「导入课表」→ 顶部切到「教务系统导入」→ 选择学年与学期 → 输入学号、密码登录学校正方教务系统，自动读取对应学期课表。导入前会显示预览，可以选替换或追加。

学年默认取当前学年，可选前后各一年，补导上一学年或开学前先导下一学年都不用改手机时间。

**不需要学校配合、不需要自建服务器。** 受微信网络层对请求头/Cookie 的处理方式影响，这条路径在部分真机上会失败；失败时按页面给出的检查项排查，或切到上面的 PDF 导入、手动添加单门课程。

登录直连 `https://jwglxt.buct.edu.cn`，学号与密码只在本机内存中使用，不上传、不保存、不写入日志。

#### 上线前必须做的一步：配置服务器域名

小程序的网络请求默认被限制在报备过的域名内。没配这一步，真机会报 `request 合法域名校验出错`（开发者工具里勾了「不校验合法域名」是看不出来的）。

1. 微信公众平台 → 开发 → 开发管理 → 开发设置 → **服务器域名**
2. 「request 合法域名」新增 `https://jwglxt.buct.edu.cn`
3. 保存后回到开发者工具重新编译
4. 个人主体同样可以配置，无需认证

**域名填写规则（很容易配错）：**

| 写法 | 结果 |
|---|---|
| `https://jwglxt.buct.edu.cn` | ✅ 正确 |
| `https://jwglxt.buct.edu.cn/jwglxt/` | ❌ 带路径，保存时报格式错误 |
| `https://jwglxt.buct.edu.cn:443` | ❌ 不允许带端口 |
| `jwglxt.buct.edu.cn` | ❌ 必须带 `https://` |
| `https://buct.edu.cn` | ⚠️ 能保存但不生效，域名精确匹配、不向下通配子域 |

配置的是**域名授权**而非具体接口，配好后该域名下任意路径都可请求。`project.config.json` 里的 `urlCheck` 已设为 `true`，本地编译就会按真实域名规则校验，避免"工具里能跑、真机挂掉"。

#### 导入流程

| 步骤 | 请求 | 作用 |
|---|---|---|
| 1 | `GET /jwglxt/xtgl/login_slogin.html` | 取 csrftoken 与密码加密标记 |
| 2 | `GET /jwglxt/xtgl/login_getPublicKey.html` | 取 RSA 公钥（本校公钥不在页面 HTML 里） |
| 3 | `POST /jwglxt/xtgl/login_slogin.html` | 提交学号与 RSA 密文 |
| 4 | `POST /jwglxt/kbcx/xskbcx_cxXsKb.html` | 取课表 kbList JSON |

`utils/jw/zfClient.js` 是纯协议层（RSA 加密、登录页解析、kbList 解析），无网络、无存储；`utils/jw/session.js` 负责 Cookie 罐与四个请求的串联。

#### 密码边界

- 密码只在本机内存中用于**一次 RSA 加密**，加密后立即提交给学校服务器，**不落盘、不上传第三方、不写日志**
- 明文密码不会出现在任何 storage、错误信息或网络请求中
- 导入成功、或遇到学号密码类失败（密码错误、账号锁定、需要验证码）时，密码输入框立即清空；断网、域名未配置这类环境问题会保留输入，方便直接重试

#### 这套实现的三个坑（已在代码里处理）

1. **modulus 带前导 `0x00` 字节**：Base64 解出 129 字节，但真实模长是 1024 位 = 128 字节。按 129 算会导致填充块多一字节，服务器私钥解不开 → 表现为"密码正确也说密码错"。
2. **教务实际路径含 `/jwglxt` 段**：拼成 `域名/kbcx/...` 会 404，表现为"登录成功但拿不到课表"。
3. **首页含退出链接**：登录成功后返回的首页里有指向 `login_slogin.html` 的链接，按文件名判断会把成功误判为失败，只能看有没有 `name="yhm"` 的输入框。

## 小鸮：一个跑在本机的迷你 Agent

小鸮不接大模型，也没有后端。它用一个很小的 Agent 循环把「自然语言 → 动作」跑通：

```text
输入 → NLU 抽槽 → 意图打分 → 选工具 → 缺槽反问 → 执行 → 记忆
```

| 环节 | 实现 | 文件 |
|---|---|---|
| 抽槽 | 时间（今天/明天/周X/下周X/下下周/第十周）、**时段**（上午/下午/晚上/第 3-4 节）、课程名、记事内容 | `utils/agent/nlu.js` |
| 课程名识别 | 全名精确 → 跳字简称（子序列，`高数`→高等数学）→ 错别字（编辑距离 ≤1）；两字简称标记为弱匹配，避免误伤 | 同上 |
| 意图打分 | 每个工具带一组「触发词 + 权重」，命中累加取最高分；同分按 priority 让更具体的胜出。顺序无关，权重可调 | `utils/agent/index.js` |
| 工具表 | 14 个工具：周课表、日课表（可加时段）、下一节、今日剩余、空档日、某门课、记事、待办、导入指引、隐私、学期、校园服务、帮助、打招呼 | `utils/agent/index.js` |
| 缺槽反问 | 没说课名就问「哪门课？」，没说内容就问「要记什么？」；两门像的课会让你选 | 同上 |
| 记忆 | 记住上一个工具与槽位，`那周三呢`「明天呢」「它呢」能顺着接上；`memory` 只在页面内存里，不落盘 | 同上 |
| 动作 | `记一下 周五交实验报告` 返回 `action.createNote`，由页面写存储（utils 层不碰 wx API） | `pages/uni/index.js` |
| 兜底 | BM25（词频饱和 + 长度归一化）检索 9 条 FAQ，中文按 bigram 切词并做同义词归一；归一化分数低于 0.2 才承认答不上来 | `utils/agent/faq.js` |

调参数时可以直接看打分，不用猜：

```bash
node -e "console.log(require('./utils/agent/index.js').explain('周三下午有什么课', {}))"
# [ { name: 'day_schedule', score: 7 } ]
```

**为什么不用大模型**：本地直连会暴露 API Key、需要在小程序后台配域名白名单，且与"数据不出本机"的定位冲突。参考过 [miniAi](https://github.com/yuanlin-yu/miniAi)（工具调用 + 记忆 + RAG）、[smart-school](https://github.com/daoqiugsy/smart-school)（简单问题走 workflow、复杂问题才上 agent），最后取的是它们的**结构**，把推理换成了可解释的规则与检索。

**能答与不能答**都写死在工具表里：课表类问题全部有确定答案；闲聊、写文案、查成绩这类会明确说"答不上来"并给出可问的例子，不编造。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 选择本仓库目录。
3. `project.config.json` 里的 `appid` 已填好本项目的小程序 AppID，直接编译即可；如果你要发布自己的版本，换成你自己的 AppID（AppID 不是密钥，可以公开，但不要提交 `project.private.config.json`）。
4. 点击“编译”。

项目使用微信原生小程序语法，无第三方运行时依赖，也不需要执行 `npm install`。

> **隐私说明**：公开仓库版本已移除真实课表 PDF、本地私有配置与示例身份信息。AppID 是开发者本人的小程序 ID（不是密钥，可公开），示例姓名与学号仍为占位符。以后上传时请使用清理过的发布副本，不要直接把整个项目文件夹拖进 GitHub 网页上传——网页上传会忽略 `.gitignore`，会把本地样本和私有配置一起带上去。

## 数据说明

教务导入时输入的学号与密码**只在内存中使用**：密码经 RSA 加密后直接提交给学校教务系统，不写入任何 storage、不进日志、不经第三方服务器，导入结束后立即从页面数据中清除。

PDF 导入时选择的文件**只在本机内存中解析**：不写入任何 storage、不进日志、不经过第三方服务器，解析完成后立即释放。

课程、设置、记事、头像昵称与小鸮历史通过 `wx.setStorageSync` 保存在当前微信客户端内。清理小程序数据或卸载后，本地数据会被删除。

头像使用微信官方「头像昵称填写能力」选取（`open-type="chooseAvatar"` + `input type="nickname"`），选完转存到小程序用户目录，不经过服务器。这里没有做"微信一键登录"：真正的登录态需要服务端用 `code` 换 openid（或云开发），本项目没有后端；手机号快速验证还要求非个人主体。

## 图标资源

`assets/icons/` 与 `assets/tabbar/` 下的 PNG 全部由 `scripts/build-icons.js` 生成，改图标只需要改脚本里的 SVG 路径再重跑：

```bash
node scripts/build-icons.js
```

脚本用 macOS 自带的 `sips` 把 SVG 渲染成带透明通道的 PNG（服务图标 192px、导航图标 81px）。换到 Windows / Linux 时把 `sips` 换成 `rsvg-convert` 或 ImageMagick 即可。

### 吉祥物

`assets/owl/` 放的是进包版本，统一压到 **256px**（显示尺寸最大 220rpx，足够清晰）：

| 文件 | 用在哪 |
|---|---|
| `owl-hello.png` | 小鸮页空状态 |
| `owl-think.png` | 小鸮回答的默认头像 |
| `owl-confused.png` | 小鸮答不上来时的头像 |
| `owl-study.png` | 课表为空 |
| `owl-sleep.png` | 当天没有记事、历史为空 |
| `owl-celebrate.png` | 课表导入完成 |

原始素材（1024 源图 + 512 成品，约 11MB）放在本地 `assets/mascot/`，已在 `.gitignore` 与 `packOptions.ignore` 里排除——**既不进仓库也不进包**。要换表情时从原图重新压一张 256px 放进 `assets/owl/` 即可。

> 体积红线：小程序主包上限 2MB。当前包约 **937KB**；直接放 10 张 512px（2.3MB）会上传失败。
