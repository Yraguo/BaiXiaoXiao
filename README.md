# 百小鸮 · 北化校园助手（微信小程序）

课表、记事、校园入口，一个**不联网也能用**的校园小程序。原生微信小程序实现，零第三方运行时依赖，没有后端。

> 本仓库早期是一版 uni-app 实现，现已整体替换为 `bxx/` 下的原生小程序版本；旧代码仍可在提交历史里找到。

## 功能

| 模块 | 能做什么 |
|---|---|
| **课表** | 按周查看，左右滑动或点箭头切周，自动定位本周、高亮今天与当前节次，显示下一节课与倒计时 |
| **课表导入** | ① 选课表 PDF 本机解析（默认）；② 直连正方教务系统登录抓取。导入前可预览，可替换或追加 |
| **记事** | 42 格月历，有记事的日期打点，点某天看当天待办；支持日期归档、完成状态、二次确认删除 |
| **小鸮** | 本机 Agent：回答本周几节课、某天课表、下一节在哪、某门课第几周、今天还剩几节；能直接说「记一下 周五交实验报告」 |
| **校园服务** | 九个常用入口（教务、图书馆、门户、校园网…），配好网址的点击复制链接 |
| **我的** | 头像昵称修改（微信头像昵称填写能力）、课表设置、数据统计与本机数据清理 |

## 快速开始

```bash
# 单元测试（Node 18+，不需要 npm install）
cd bxx && npm test
```

在微信开发者工具里：

1. 选择「导入项目」，目录选 **`bxx/`**（不是仓库根目录）
2. `project.config.json` 里的 AppID 已填好，直接编译；要发布自己的版本就换成你自己的
3. 点击「编译」

项目使用微信原生小程序语法，**没有任何第三方运行时依赖**，也不需要 `npm install`。

## 课表导入

课表网格下方的「导入课表」默认进入 **PDF 导入**（教务直连在部分真机过不了，PDF 是本机解析的稳定路径）。页面顶部可切换到教务直连。

### ① PDF 导入（默认）

课表页 →「导入课表」→「选择 PDF 并导入」→ 确认预览 → 选替换或追加。

导出方式：浏览器进教务「信息查询 → 学生课表查询」，选好学年学期点「输出 PDF」，把文件发到微信（文件传输助手即可），再回小程序选择。

**不需要登录、不需要学号密码、不联网、不上传。** 解析链路全部在小程序内（`utils/pdf/`）：

1. `inflate.js` 自研 DEFLATE 解压 `FlateDecode` 内容流（与 Node zlib 逐字节比对过）
2. `extract.js` 从 `Tm` / `Td` 取坐标、`Tj` 取文字，按 UCS-2 还原中文
3. `parser.js` 用「星期一 ~ 星期日」表头锚定七列，按坐标归星期、按行拼接课程块
4. `courses.js` 映射成课表页使用的对象，复用同一套 `parseWeeks` 与配色

只支持学校课表页导出的**表格格式** PDF（带文字层、`UniGB-UCS2-H`、`FlateDecode`）。截图、扫描件、加密 PDF、模板变化都会给出具体原因，不会写入半成品。

### ② 教务系统直连（可选）

输入学号密码登录正方 `jwglxt`，自动读取指定学年学期的课表。**上线前必须配置服务器域名**：

> 微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名 → request 合法域名，添加 `https://jwglxt.buct.edu.cn`
>
> 只能填域名：带路径、带端口、少了 `https://` 都会保存失败；`jwglxt` 是多级子域，配 `buct.edu.cn` 不会生效。

密码只在本机内存里做一次 RSA 加密后提交给学校服务器，不落盘、不上传第三方、不写日志；导入成功或认证类失败后立即清空输入框。

## 小鸮：一个跑在本机的迷你 Agent

不接大模型，也没有后端。它用一个很小的 Agent 循环把「自然语言 → 动作」跑通：

```text
输入 → 抽槽 → 意图打分 → 选工具 → 缺槽反问 → 执行 → 记忆
```

| 环节 | 实现 |
|---|---|
| 抽槽 | 时间（今天/明天/周X/下周X/下下周/第十周）、时段（上午/下午/晚上/第 3-4 节）、课程名、记事内容 |
| 课程名识别 | 全名精确 → 跳字简称（子序列，`高数`→高等数学）→ 错别字（编辑距离 ≤1）；两字简称标记为弱匹配，避免「数据还在吗」误命中《数据结构》 |
| 意图打分 | 每个工具声明「触发词 + 权重」，命中累加取最高；同分按优先级让更具体的胜出。顺序无关、权重可调 |
| 工具表 | 14 个：周课表、日课表（可加时段）、下一节、今日剩余、空档日、某门课、记事、待办、导入指引、隐私、学期、校园服务、帮助、打招呼 |
| 缺槽反问 | 没说课名就问「哪门课？」，没说内容就问「要记什么？」；两门像的课会让你选 |
| 记忆 | 记住上一轮工具与槽位，`那周三呢`「明天呢」「它呢」能顺着接上；只存在页面内存，不落盘 |
| 动作 | `记一下 周五交实验报告` 返回 `action.createNote`，由页面写存储（utils 层不碰 wx API） |
| 兜底 | BM25 检索 9 条 FAQ（中文按 bigram 切词 + 同义词归一），归一化分数低于 0.2 才承认答不上来 |

调参时可以直接看打分，不用猜：

```bash
node -e "console.log(require('./bxx/utils/agent/index.js').explain('周三下午有什么课', {}))"
# [ { name: 'day_schedule', score: 7 } ]
```

**为什么不用大模型**：客户端放不住 API Key（抓包就能拿走）；要为它配域名白名单；而课表、记事是个人数据，不该为了回答「明天几节课」把整份课表传到别人服务器。代价是覆盖面有限，好处是**不会编**——答不上来就直说。

## 数据与隐私

- 课表、记事、头像昵称、对话历史全部存在 `wx.setStorageSync`，卸载或清理小程序数据即消失
- PDF 只在本机内存解析；教务密码只用于一次 RSA 加密，不落盘
- 小程序**没有任何后端请求**，除了教务直连那一次（用户主动发起）
- 头像使用微信官方「头像昵称填写能力」，选完转存到小程序用户目录，不经过服务器
- 仓库不含真实课表 PDF、个人姓名学号与本地私有配置；PDF 测试样本被 `.gitignore` 排除，缺失时相关用例自动跳过

## 工程实现

```
bxx/
├── pages/           课表、记事（日历）、小鸮、校园、我的 + 课程/记事编辑、设置、两个导入页
├── utils/
│   ├── jw/          正方协议层（RSA、登录页解析、Cookie 罐、四个请求）与课程映射
│   ├── pdf/         自研 DEFLATE、文字坐标提取、课程块还原
│   ├── agent/       小鸮的 NLU、工具表、BM25 兜底
│   └── 其它         日期/周次、配色、存储、二次确认、个人资料
├── data/            示例课表、默认作息、校园服务清单
├── assets/          品牌图、校园服务图标、tabBar 图标、吉祥物
├── scripts/         图标生成、教务链路探测、素材处理（不参与打包）
└── tests/           Node 单元与结构测试
```

**体积红线**：小程序主包上限 2MB。吉祥物原图（10 张 512px）就有 2.3MB，直接打包会失败——所以只把压到 256px 的 6 张放进 `assets/owl/`，原图与仓库、安装包都隔离。当前打包体积约 **937KB**。

**图标**：`assets/icons/`、`assets/tabbar/` 下的 PNG 全部由 `scripts/build-icons.js` 从 SVG 路径生成，改图标只改脚本再重跑。

### 踩过的几个坑

- **正方 modulus 带前导 `0x00`**：Base64 解出 129 字节，真实模长是 1024 位 = 128 字节。按 129 算，服务端私钥解不开，表现为「密码正确也说密码错」。
- **`<button>` 在 flex 容器里宽度失效**：周次箭头、悬浮按钮、输入区都被拉成过胶囊，把相邻内容挤成一列。改用 `view` + `flex: 0 0 68rpx` + min/max 四重锁宽。
- **WXML 与 WXSS 半更新**：删掉某个元素的样式、却还在跑旧 WXML 时，那一块会退化成无样式裸文本，看起来像「字体变了」。清缓存重编译即可。

## 已知限制

- 教务直连受微信网络层与学校多节点会话影响，**部分真机登录失败**；PDF 导入不受影响
- 仅适配正方教务系统；PDF 解析仅支持学校课表页导出的表格格式
- 空教室、考试成绩、选课等没有数据源，暂不提供
- 日历暂未接入农历/节气
- 提审前需要完成**小程序备案**，服务类目建议「工具-效率」，简介里避免出现校名
- 应用内入口受小程序业务域名限制，未适配的校园入口只做提示
