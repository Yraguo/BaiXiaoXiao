# 百小鸮 · 校园小程序

北京化工大学校园学习生活小程序的课程项目代码，代码位于 [`bxx/`](bxx/)。

## 快速开始

1. 用微信开发者工具导入 `bxx/` 目录
2. 把 `bxx/project.config.json` 里的 `appid` 占位符改成自己的小程序 AppID
3. 点击「编译」；运行 `npm test` 可执行 Node 侧单元测试

功能说明、两种课表导入方式与运行细节见 [bxx/README.md](bxx/README.md)。

## 隐私说明

公开仓库已做清理：

- 不含任何真实课表 PDF、个人姓名、学号或教师信息
- 不含 `project.private.config.json` 等本地私有配置
- AppID 与示例身份信息均为占位符
- 课表 PDF 解析样本不随仓库分发，相关测试在没有本地样本时自动跳过
